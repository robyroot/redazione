# Ubuntu 26.10 arriva il 15 ottobre: GNOME 51, Linux 7.3 e un GRUB più sicuro

Manca meno di una settimana: il 15 ottobre Canonical rilascerà Ubuntu 26.10, alias "Oracular Orangutan". Questa versione non è una LTS (quella arriverà con 28.04), ma porta con sé cambiamenti interessanti — alcuni dei quali riguardano direttamente la sicurezza del boot.

## Le novità principali

### GNOME 51 come desktop di default
Ubuntu 26.10 sarà la prima release stabile a includere GNOME 51. Le novità visibili per gli utenti:
- Nuove animazioni più fluide nelle transizioni
- Miglioramenti al pannello di notifiche
- Refinamenti all'app Files (Nautilus)
- Maggiore compatibilità con applicazioni Flatpak

GNOME 51 era in sviluppo da maggio, con la release finale avvenuta a settembre: Ubuntu 26.10 lo porta agli utenti stabili per la prima volta.

### Linux 7.3 (quasi finale)
Il kernel incluso sarà Linux 7.3 release candidate, dato che il kernel finale 7.3 uscirà qualche giorno dopo Ubuntu stessa. Canonical ha già annunciato che farà un aggiornamento trasparente al kernel finale pochi giorni dopo il lancio.

Linux 7.3 porta:
- Driver RGB per i LED delle APU Ryzen AI Halo
- Abilitazione AMD Zen6 (i processori di nuova generazione)
- Driver iniziale per il controller Steam 2026
- Vari miglioramenti alle performance su hardware recente

### Il grande cambiamento: GRUB firmato e snello

Questa è forse la novità più significativa dal punto di vista della sicurezza, anche se molti utenti non la noteranno direttamente. Canonical ha rivisto completamente il bootloader GRUB:

**GRUB firmato digitalmente**: il bootloader sarà ora firmato con chiave Canonical, rafforzando la catena di Secure Boot. Questo rende molto più difficile per malware o attaccanti fisici alterare il processo di avvio senza essere rilevati.

**GRUB snellito**: Canonical ha rimosso moduli non necessari dal GRUB, riducendo la superficie di attacco. Un GRUB con meno codice è un GRUB con meno potenziali vulnerabilità.

**dbus-broker come default**: Ubuntu sostituisce dbus-daemon con dbus-broker, un'implementazione più moderna e sicura del bus di sistema. Il cambiamento è trasparente per gli utenti ma migliora stabilità e performance del sistema.

## Vale la pena aggiornare subito?

Dipende dal tuo profilo:

**Aggiorna subito se:**
- Hai hardware recente (AMD Zen6, Ryzen AI) e vuoi i driver aggiornati
- Vuoi GNOME 51 e le ultime versioni dei software
- Usi Ubuntu come macchina di sviluppo e vuoi il kernel più recente

**Aspetta qualche settimana se:**
- Usi la macchina per lavoro critico e preferisci aspettare le patch post-lancio
- Stai su Ubuntu 26.04 LTS e non hai bisogno delle novità — la LTS è supportata fino al 2029

**Non aggiornare se:**
- Sei su Ubuntu 24.04 LTS: l'upgrade diretto a 26.10 non è supportato. Prima upgradi a 26.04 LTS.

## Come prepararsi all'aggiornamento

Quando sarà disponibile il 15 ottobre:

```bash
# Prima di tutto: backup
# (usa il tuo metodo preferito: rsync, Timeshift, ecc.)

# Aggiorna il sistema attuale
sudo apt update && sudo apt upgrade -y

# L'upgrade alla nuova versione apparirà automaticamente
# in Software Updater, oppure forzalo da terminale:
sudo do-release-upgrade -d
```

Il flag `-d` è necessario per le versioni non-LTS. Toglilo se vuoi aspettare la release stabile (disponibile di solito 2-3 giorni dopo il lancio ufficiale).

## Le altre flavor

Se non usi GNOME, non preoccuparti: tutte le flavor ufficiali si aggiornano insieme:
- **Kubuntu 26.10** porterà KDE Plasma 6.8 (in uscita il 14 ottobre, un giorno prima)
- **Ubuntu MATE**, **Xubuntu**, **Lubuntu** seguiranno con i rispettivi desktop aggiornati
- **Ubuntu Server** include le stesse novità kernel e sicurezza
