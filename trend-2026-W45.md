1. **Linux Kernel 7.4-rc1: la finestra di merge più grande della storia**

2. **CVE-2026-98432: vulnerabilità critica CVSS 9.8 nel kernel Linux**
   - Perché è rilevante: Una use-after-free nel codice IPv4 TCP del kernel potrebbe consentire a un attaccante non autenticato di ottenere privilegi root su server con MPTCP abilitato. Red Hat, Debian, Amazon Linux e SUSE hanno già rilasciato patch. Tutti i sysadmin Linux devono aggiornare subito.
   - Fonte/riferimento: AWS Security Bulletin 2026-160 (https://aws.amazon.com/security/security-bulletins/2026-160-aws/); The420.in analysis (https://the420.in/tech-talk/critical-linux-kernel-vulnerability-cve-2026-98432/)

## Note Editoriali

**Pattern emergenti questa settimana:**

- **La sicurezza del kernel è tornata in primo piano.** CVE-2026-98432 con CVSS 9.8 è un promemoria che anche il software più audited al mondo non è immune. L'abbinamento con la merge window record di Linux 7.4 (20k commit!) crea un'ottima narrativa: più codice = più superficie d'attacco.

- **L'ecosistema AI come vettore di attacco.** Gli attacchi supply-chain a Claude Code extensions e LiteLLM segnalano un cambiamento: gli strumenti AI per sviluppatori sono diventati un target primario. È un argomento perfetto per RobyRoot, che si rivolge a professionisti IT che adottano rapidamente questi strumenti.

- **AI locale in piena maturità.** Ollama a 52 milioni di download mensili non è più un progetto di nicchia. La tensione tra cloud tiers (con i relativi rischi privacy) e modalità locale è un tema che il pubblico di RobyRoot seguirà con grande interesse.

- **Scadenze normative di dicembre.** L'EU AI Act si avvicina con obblighi concreti. Dicembre 2026 è vicino: un articolo pratico su cosa fare adesso può essere molto utile e tempestivo.

- **Settimana record per il kernel.** Con Linux 7.2 a fine vita, Linux 7.4-rc1 in sviluppo e la merge window più grande della storia, questa è probabilmente la settimana più importante per il kernel degli ultimi anni.
