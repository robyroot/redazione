# Web Grafica Skills — Settimana 20260803

## 🏆 Top 3 scoperte della settimana

1. **CSS Scroll-Driven Animations** — Supporto universale raggiunto nel 2026 (Chrome, Firefox, Safari, Edge). Zero JavaScript per scroll progress bar, parallax, e reveal-on-scroll: il browser gestisce tutto sul compositor thread con performance di livello nativo. Tecnica obbligatoria per chiunque costruisca landing page moderne.

2. **Three.js r184 + WebGPU + TSL** — La release di aprile 2026 porta WebGPU in produzione su tutti i browser con fino a 10× più performance in scenari complessi. Il Three Shading Language (TSL) permette di scrivere shader una sola volta compilabili sia in GLSL che in WGSL, eliminando la duplicazione di codice. RenderPipeline semplifica drasticamente il post-processing (bloom, AO, blur).

3. **shadcn/ui adotta Base UI come default** — Da luglio 2026, tutti i nuovi progetti shadcn/ui montano Base UI invece di Radix UI. Segnala un cambio importante nell'ecosistema dei component library React: Base UI offre primitive più leggere e zero-styled, con Radix ancora supportato per retrocompatibilità.

## Highlight della settimana

Il 2026 segna la maturità definitiva delle animazioni CSS native: con scroll-driven animations universali, `@starting-style`, `@property` tipizzato e `scroll-triggered` in Chrome 145, il bisogno di librerie JavaScript per la maggior parte degli effetti visivi si è ridotto drasticamente. Al tempo stesso, il confine tra "designer" e "developer" si assottiglia ulteriormente grazie a tool AI come Recraft (SVG nativo da testo) e Spline AI (3D web da prompt): asset che richiedevano ore di lavoro specializzato si generano in minuti, spostando il valore verso la direzione creativa e l'integrazione tecnica. Sul fronte dei component library, il pivot di shadcn/ui verso Base UI segnala la ricerca di primitive più leggere e flessibili rispetto a Radix — un trend di "return to fundamentals" che si riflette anche nell'estetica Tactile Brutalism, dove raw geometry e bordi spessi battono il minimalismo ultra-levigato degli anni scorsi.
