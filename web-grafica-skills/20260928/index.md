# Web Grafica Skills — Settimana 20260928

## 🏆 Top 3 scoperte della settimana

1. **CSS Scroll-Driven Animations native** — Supporto universale in tutti i browser moderni nel 2026: si possono finalmente usare in produzione senza JavaScript per parallax, reveal-on-scroll e progress bar, con performance sul compositor thread (60fps garantiti). Insieme a `@property`, rende GSAP ScrollTrigger opzionale per il 95% dei casi d'uso comuni.

2. **Three.js r186 + WebGPU production-ready** — Il renderer WebGPU ha raggiunto stabilità con fallback automatico a WebGL 2 su browser older. Fino a 10x più performante di WebGL in scenari complessi. Il nuovo shader language TSL semplifica la scrittura di material custom. Il 3D immersivo diventa accessibile anche a team senza specialisti.

3. **shadcn/ui migra a Base UI (luglio 2026)** — Il component system più usato per React nel 2026 ha cambiato le fondamenta da Radix a Base UI (6M+ downloads/settimana). Nessuna deprecation forzata per chi usa Radix, ma i nuovi progetti devono conoscere la nuova architettura per non creare debito tecnico.

## Highlight della settimana

Il web design nel settembre 2026 vive una convergenza storica: CSS nativo ha colmato il gap con le librerie JavaScript per la maggior parte delle animazioni (scroll-driven, micro-interactions, transizioni), mentre il 3D sul web è diventato mainstream grazie a WebGPU e React Three Fiber. Sul fronte AI, il salto qualitativo è nell'output vettoriale nativo (Recraft, Firefly) che rende i tool AI finalmente utilizzabili per asset web production-ready senza conversioni. Il trend estetico si divide tra "Invisible Architecture" (UI minimalista che scompare) e "Tactile Brutalism" (personalità raw e imperfezioni intenzionali), con la tipografia cinetica a variabile come elemento unificatore tra i due poli.
