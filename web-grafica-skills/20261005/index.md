# Web Grafica Skills — Settimana 20261005

## 🏆 Top 3 scoperte della settimana

1. **GSAP ora 100% gratuito (inclusi plugin premium)** — Da aprile 2025, a seguito dell'acquisizione da parte di Webflow, GSAP ha reso gratuiti tutti i plugin che erano a pagamento (SplitText, MorphSVG, DrawSVG, ecc.). Con 18,7M download npm ad agosto 2026, è lo standard assoluto per animazioni web professionali. Zero scuse per non usarlo.

2. **CSS Scroll-Driven Animations — baseline su tutti i browser** — Le animazioni guidate dallo scroll sono ora supportate nativamente da Chrome 115+, Firefox 126+, Safari 17.2+, Edge 115+. Non serve più GSAP ScrollTrigger o IntersectionObserver per l'80% degli effetti scroll. Girano sul compositor thread: performance ottimale out of the box.

3. **Recraft V4.1 — unico AI che genera SVG vettoriali nativi** — Il solo modello AI che produce file `.svg` con path realmente editabili (non SVG wrappati attorno a un PNG). V4.1 è 2x più veloce e 13-16% più economico. Trasforma il flusso di lavoro per icone, loghi e illustrazioni UI.

## Highlight della settimana

Il confine tra CSS nativo e librerie JavaScript per animazioni si sta assottigliando rapidamente: nel 2026 le scroll-driven animations, le view transitions, i CSS carousels nativi, e `@property` coprono casi d'uso che fino a un anno fa richiedevano GSAP o Framer Motion. Il risultato è che i team possono finalmente ridurre le dipendenze JS per gli effetti base, riservando le librerie per animazioni davvero complesse. Sul fronte AI, la novità più impattante è Recraft che democratizza la creazione di grafica vettoriale professionale: chiunque può ora generare icone e illustrazioni SVG editabili con un prompt, integrando il risultato direttamente nel design system. Il trend Liquid Glass e i Bento Grid restano dominanti per l'impatto visivo immediato, ma la tendenza di fondo è verso interfacce più calme e funzionali, dove il motion ha uno scopo e non è decorativo.
