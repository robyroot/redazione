## 🏆 Top 3 scoperte della settimana

1. **CSS Scroll-Driven Animations (native)** — Chrome 145 ha aggiunto le scroll-triggered animations, completando lo stack che permette di rimpiazzare GSAP ScrollTrigger e Framer Motion per l'80% dei casi d'uso con CSS puro. Supporto Firefox in arrivo (ora in Nightly). Zero JS, zero dipendenze, performance native.

2. **GSAP ora MIT License** — Dopo l'acquisizione Webflow (fine 2024), GSAP core + plugin sono gratuiti per qualsiasi uso. Cambia radicalmente il calcolo costi per progetti commerciali: il motore di animazione più potente del web è ora open source.

3. **Recraft V4 SVG** — L'unico generatore AI 2026 che produce veri SVG editabili con path puliti. Game changer per chi ha bisogno di illustrazioni e icone web-ready scalabili generate su misura senza dover tracciare output raster.

## Highlight della settimana

Ottobre 2026 segna un punto di maturità del web design: il CSS nativo ha raggiunto una potenza tale da sostituire la maggior parte delle librerie JS per animazioni scroll, entry effects e micro-interazioni. Il confine tra ciò che richiedeva JavaScript e ciò che si può fare con soli CSS è drasticamente spostato, con `animation-timeline`, `@starting-style`, `@property` e i nuovi pseudo-elementi per carousel che coprono scenari un tempo impensabili. Sul fronte delle librerie JS, la grande novità è la liberalizzazione di GSAP con licenza MIT, mentre Three.js r186 porta WebGPU come standard produttivo universale con supporto anche su iOS Safari. Visivamente, il 2026 è l'anno del ritorno alla personalità: brutalism tattico, bento grid, variable fonts cinetici e palette calde sostituiscono il minimalismo sterile. I tool AI si specializzano: Recraft per SVG vettoriali, Ideogram per testo in immagine, Stitch per UI da prompt — ciascuno eccelle in un dominio specifico invece di coprire tutto male.
