# Tool AI per Grafica Web — Settimana 20261019

## [Recraft](https://www.recraft.ai)
**Facilità:** ⭐⭐⭐⭐⭐ | **Impatto visivo:** ⭐⭐⭐⭐⭐ | **Browser:** Web app

Genera grafica vettoriale SVG editabile direttamente da prompt testuale. A differenza di Midjourney/DALL-E che producono raster, Recraft restituisce SVG scalabili e modificabili — perfetti per icone, illustrazioni, loghi web che devono scalare a qualsiasi dimensione.

**Come usarlo:** Vai su recraft.ai → seleziona output type "SVG" o "Vector" → descrivi l'icona/illustrazione → scarica il file SVG → incollalo nel codice.

**Workflow tipico:**
```
Prompt: "minimal flat icon of a rocket launching, geometric style, single color, suitable for web"
Output: SVG editabile con path separati per ogni elemento
```

**Quando usarlo:** Icone custom, illustrazioni hero, pattern decorativi, grafica che deve essere scalabile e modificabile nel codice.

## [Google Stitch](https://stitch.withgoogle.com)
**Facilità:** ⭐⭐⭐⭐ | **Impatto visivo:** ⭐⭐⭐⭐⭐ | **Browser:** Web app

Converte prompt testuali in wireframe/mockup ad alta fedeltà di interfacce web e app. Può esportare su Figma o generare HTML/CSS di base. Il tool di Google specificamente pensato per il design di layout di siti.

**Esempio prompt:**
```
"SaaS landing page with hero section, dark theme, featuring a dashboard 
screenshot, pricing table with 3 tiers, and testimonials grid"
```

**Quando usarlo:** Prototipazione rapida di layout, wireframe di alta qualità da presentare ai clienti, ispirazione per strutture di pagina.

## [Adobe Firefly](https://firefly.adobe.com)
**Facilità:** ⭐⭐⭐⭐⭐ | **Impatto visivo:** ⭐⭐⭐⭐ | **Browser:** Web app + integrazione Photoshop/Illustrator

La scelta professionale per output commercialmente sicuri: Adobe garantisce che il training data è solo contenuto licenziato, quindi le immagini generate sono libere da copyright claims. Si integra con l'ecosistema Adobe.

**Feature chiave per web:**
- **Generative Fill:** rimuovi o sostituisci oggetti nelle foto con AI
- **Text to Image:** genera sfondi, texture, elementi decorativi
- **Generate Similar:** parti da un'immagine esistente e crea varianti

**Quando usarlo:** Progetti client dove la provenienza dell'immagine è legalmente rilevante, editing foto per hero images, creazione di asset per campagne.

## [Canva Magic Studio](https://www.canva.com/ai-image-generator/)
**Facilità:** ⭐⭐⭐⭐⭐ | **Impatto visivo:** ⭐⭐⭐ | **Browser:** Web app

**Quando usarlo:** Social media assets, banner pubblicitari, materiali marketing, thumbnail.
