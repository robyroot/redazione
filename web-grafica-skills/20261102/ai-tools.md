# Tool AI per Generare Grafica Web — Novembre 2026

## [Recraft — Vettori SVG AI-Generated](https://recraft.ai)
**Facilità:** ⭐⭐⭐⭐⭐ | **Impatto visivo:** ⭐⭐⭐⭐⭐ | **Output:** SVG / PNG / WebP

Il punto di forza di Recraft è che genera veri vettori SVG editabili, non raster. Fondamentale per loghi, icone e illustrazioni web che devono scalare a qualsiasi dimensione senza perdere qualità. Stile coerente all'interno di un brand.

**Come usarlo:**
```
1. Vai su recraft.ai
2. Scegli "Vector illustration" come tipo di output
3. Prompt: "minimal flat icon, [soggetto], monochrome, SVG, web design"
4. Esporta in SVG e apri in Figma/Illustrator per editare i path
```

**Quando usarlo:** icone custom, hero illustrations, sfondi SVG animabili con CSS/GSAP, loghi per client senza licenza da acquistare.

## [Adobe Firefly 4 — Immagini con Licenza Commerciale Pulita](https://firefly.adobe.com)
**Facilità:** ⭐⭐⭐⭐⭐ | **Impatto visivo:** ⭐⭐⭐⭐ | **Output:** PNG / JPG

Addestrato esclusivamente su Adobe Stock e contenuti di pubblico dominio: zero rischi di copyright per usi commerciali. Integrato in Photoshop, Illustrator e Express. Ideale per asset di produzione.

**Workflow tipo:**
```
1. Genera l'immagine su firefly.adobe.com con prompt descrittivo
2. Usa "Generative Fill" in Photoshop per estendere/modificare
3. Usa "Text to Vector" in Illustrator per grafica vettoriale
4. Scarica con commercial use license inclusa
```

**Quando usarlo:** hero image per siti client, background fotografici, asset di produzione dove la licenza è non negoziabile.

## [Google Stitch — UI da Testo/Voce](https://stitch.withgoogle.com)
**Facilità:** ⭐⭐⭐⭐ | **Impatto visivo:** ⭐⭐⭐⭐ | **Output:** HTML/CSS / Figma

Trasforma prompt di testo (o voce) in interfacce web e app ad alta fedeltà. Output direttamente in HTML/CSS o esportabile su Figma. Utile per prototipazione rapida e per generare basi di codice UI da raffinare.

**Workflow tipo:**
```
1. Descrivi l'interfaccia: "A SaaS dashboard with sidebar nav, KPI cards, 
   and a revenue chart, dark mode, Tailwind-style"
2. Stitch genera HTML/CSS funzionante
3. Copia in VS Code / Figma e raffina
```

**Quando usarlo:** prototipi veloci per client, basi di codice per landing page, ispirazione per layout complessi.
