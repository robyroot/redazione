# Web Grafica Skills — Settimana 20261102

## 🏆 Top 3 scoperte della settimana

1. **CSS Scroll-Driven Animations ora in Safari 26** — Con l'arrivo del supporto in Safari 26, le scroll-driven animations CSS raggiungono copertura quasi universale (Chrome/Edge/Safari). Si possono finalmente costruire effetti parallax, fade-in on scroll e progress bar senza una riga di JavaScript, aprendo la strada a un futuro in cui librerie come AOS.js diventano obsolete.

2. **Anime.js v4.5 — Alternativa MIT completa a GSAP** — La versione 4.5 di Anime.js consolida la riscrittura modulare della v4 e raggiunge performance paragonabili a GSAP su carichi concorrenti, con licenza MIT pura. Con ScrollObserver integrato e tree-shaking aggressivo, è diventata la scelta preferibile per chi vuole bundle leggeri senza rinunciare a potenza.

3. **shadcn/ui switch a Base UI come default** — Da luglio 2026 shadcn usa Base UI invece di Radix come libreria sottostante di default, aggiungendo anche React Aria come terza opzione. La migrazione per i progetti esistenti è un singolo comando; per i nuovi progetti il setup è identico. Questo cambia le dipendenze transitive e la semantica HTML dei componenti generati.

## Highlight della settimana

Novembre 2026 segna un punto di svolta nel web design: il CSS nativo ha raggiunto un livello di maturità tale da poter sostituire interi ecosistemi JavaScript per animazioni e grafica. Le scroll-driven animations con supporto Safari, i carousel nativi CSS e `@starting-style` per entry animations riducono drasticamente le dipendenze front-end. Sul fronte AI, la maturazione degli strumenti generativi porta benefici concreti al workflow: Recraft genera SVG vettoriali editabili, Adobe Firefly garantisce licenze commerciali pulite, e Google Stitch prototipa UI complete da testo. Il mercato dei componenti si consolida attorno a shadcn/ui (ora con tre "basi" tra cui scegliere) e Tailwind v4, mentre i trend visivi oscillano tra minimalismo calmo e brutalismo digitale, con la tipografia variabile che diventa infrastruttura standard per le Core Web Vitals.
